- **本机无 MSVC / Windows SDK**：`C:\Program Files (x86)\Microsoft Visual Studio\2022` 目录为空（无 VC 工具链），`Windows Kits\10` 仅含 `UnionMetadata`、无 `Lib`（缺 kernel32.lib 等系统导入库）。rust 工具链 lib 目录也只含 rust 自带的 .rlib，不含微软系统库。
- 因此**无法在本地用 msvc 目标链接**：lld-link（rust 自带 `gcc-ld/lld-link.exe`）能启动，但内部 rust-lld 报 `could not open 'kernel32.lib'`；且 lld-link 包装器要求 exe 名必须是 `lld-link.exe`（改名 link.exe 会报 `unexpected name`）。
- 结论：本地只能靠 **GitHub Actions** 的 Windows runner（自带完整 MSVC）来构建 msvc 二进制。

### PowerShell 陷阱补充
- `$PID` 是只读自动变量（当前进程 ID），不能用作脚本变量名（报 "Cannot overwrite variable PID because it is read-only or constant"）。改用 `$targetPid` 等。
